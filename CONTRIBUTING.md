# Contributing to Age of Duck

Contributions are very welcome: bug fixes, new build orders, HUD fixes for other
skins and resolutions, translations, tests, docs.

1. **Open an issue first** for anything big, so we don't duplicate work.
2. Fork the repo, create a branch, and make your change.
3. Run the tests that apply to what you touched (`python -m unittest test_<name>`).
4. Open a pull request describing what changed and why. Screenshots help for UI changes.

## Licensing of contributions

Age of Duck is released under the [MIT License](LICENSE). By submitting a pull
request you confirm that:

- you wrote the contribution (or have the right to submit it), and
- you are happy for it to be released under the MIT License, like the rest of
  the project.

Please don't add game artwork or data you don't have the right to share.
See [NOTICE.md](NOTICE.md).

## Reporting bugs

Open an issue with your Windows version, game version (Steam or Microsoft
Store), screen resolution and HUD/UI size, and what you expected to happen.
You can also ask in the [Discord](https://discord.gg/hWsa7KS9nw).
